# Official Fedora Linux copr repo for Haxefetch

## How to install this?

1. Enable Copr repo
- `dnf copr enable stefan2008/Haxefetch`

2. Refresh Fedora repos
- `dnf refresh`

3. Install Haxefetch 
- `dnf install haxefetch`
